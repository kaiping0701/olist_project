### 總結

本專案以「如何提升首購顧客的 N 天二購率」為核心問題，先完成資料匯入、資料理解與品質檢查，再依據 Data Understanding 所定義的資料品質處理規則，進行資料清理、轉換與整合，建構 Data Mart，並根據後續分析問題與分析粒度建立對應的 Analysis Mart。

完成資料倉儲整合後，透過 EDA、統計分析與機器學習，依序回答留存結構、關聯因素、二購傾向預測及策略設計問題，最終將分析證據轉化為商業決策建議與成效驗證方案。
   
---

### 1. 問題 -> 分析方法 Mapping
| 問題      | 要回答什麼            | 方法                                              | 主要產出                  |
| ------- | ---------------- | ----------------------------------------------- | --------------------- |
| Q1 留存結構 | 二購目前長什麼樣？N 應是多少？ | Cohort / 二購間隔 / Retention EDA                   | N 天 KPI、baseline      |
| Q2 關聯因素 | 哪些首購特徵與N天二購相關？     | EDA / 統計檢定 / Effect Size / Logistic             | 關聯因素                  |
| Q3 二購傾向 | 能否辨識高二購潛力顧客？     | Classification / Ranking                        | repurchase probability、Lift |
| Q4 策略設計 | 如何利用分析結果改善二購？    | Segmentation / Action Mapping / A/B Test Design | 商業策略與驗證方案             |

---

### 2. 整體分析流程

1. **原始資料匯入**

   將原始 CSV 欄位先以文字型別匯入 `olist_staging`，保留來源資料的原始狀態，後續再進行型別轉換與清理。

2. **資料理解與品質檢查**

   使用 SQL 理解資料表結構、粒度、關聯、缺失值、重複值與異常情況，確認資料是否足以支援核心問題。

3. **review內容AI標注**  
    建構review_comment結構化分類機制，並且利用OpenAI API進行評論分類。
   

4. **資料倉儲建構**

   - **Data Mart**：將清理與標註後的資料整合成星狀模型，建立一致且可重複使用的 Fact 與 Dimension。

   - **Analysis Mart**：根據 Q1～Q3 的分析粒度與需求，從 Data Mart 產出可直接供 EDA、統計分析及機器學習使用的分析資料表。
   

5. **EDA 與統計分析 (描述性、診斷性分析)**

   描述平台留存結構、決定 N 天觀察窗口，並分析首購特徵與二購行為之間的關聯，回答 Q1 與 Q2。

6. **機器學習與模型評估(預測性分析)**

   建立 N 天二購傾向模型，評估模型辨識與排序顧客的能力，回答 Q3。

7. **商業決策與驗證設計(處方性分析)**

   整合留存分析、關聯分析與模型結果，提出客群分層、可行動槓桿及 A/B Test 成效驗證方案，回答 Q4。
